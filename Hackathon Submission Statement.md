## Hack-Nation 7th Global AI Hackathon
### Challenge 03 — Databricks: Agentic Scientific Discovery

## Project Overview

AIE Scientific Discovery Lab is an agentic scientific discovery system that turns a research question into a closed computational discovery loop.

**Research → Hypotheses → Experiment Planning → Deterministic Selection → Execution → Evidence Analysis → Next Experiment**

> **Agents propose. Deterministic computation tests. Evidence updates. The system decides what to test next.**

AIE addresses a key limitation of AI-assisted scientific discovery: generating a plausible hypothesis is not the same as testing it. The system therefore separates AI reasoning from experimental execution and uses deterministic computational experiments to produce observations.

## What AIE Does

AIE uses an agentic pipeline to:

1. Establish a research and theoretical baseline.
2. Generate competing, falsifiable scientific hypotheses.
3. Define predicted optima, acceptable parameter windows, and falsification criteria.
4. Generate candidate computational experiments.
5. Select the most informative experiment using deterministic utility scoring.
6. Execute the selected numerical experiment without asking the LLM to generate the observations.
7. Compare observations against competing hypotheses.
8. Update hypothesis confidence from evidence.
9. Use remaining uncertainty to select the next experiment.

## Demonstrated Scientific Problem

The current demonstration asks:

> **What parameter configuration maximizes the predicted critical temperature in the computational superconductivity model?**

The benchmark uses the **Allen-Dynes Modified McMillan formalism** for phonon-mediated superconductivity.

- **Variable:** doping concentration `x`
- **Target metric:** critical temperature `Tc`
- **Benchmark:** `mcmillan_superconductor`

The observations shown in the demonstration are generated by a deterministic computational parameter sweep. They are not laboratory measurements.

## Agentic Discovery Architecture

### 1. Research Agent
Establishes the scientific baseline and synthesizes relevant theoretical context.

### 2. Hypothesis Agent
Produces competing hypotheses with explicit predictions, acceptable parameter windows, and falsification criteria.

### 3. Experiment Planner
Generates candidate parameter-sweep experiments designed to discriminate between hypotheses or reduce uncertainty.

### 4. Deterministic Experiment Selector
Scores candidate experiments using information gain, hypothesis discrimination, feasibility, cost, and risk.

### 5. Deterministic Numerical Experiment Engine
Executes the selected computational experiment and produces reproducible numerical observations and experiment signatures.

### 6. Result Analyzer
Separates parameter residuals from metric residuals and evaluates whether each hypothesis is supported or contradicted by the observation.

### 7. Next Experiment Selector
Uses the updated hypothesis state and remaining uncertainty to determine the next experiment.

Reported epistemic uncertainty decreased:

The computational search progressively concentrates around the strongest supported region.

## Scientific Integrity

AIE explicitly distinguishes computational evidence from experimentally validated scientific knowledge.

The demonstrated superconductivity result is classified as:

**MODEL-DEPENDENT**

It is not presented as laboratory confirmation.

The system separates parameter residuals from metric residuals so that metric differences cannot incorrectly masquerade as parameter contradiction.

Hypothesis identities are preserved across iterations, and posterior confidence is carried forward as the prior for the next evidence update.

## Closed-Loop Principle

```text
Scientific Question
        ↓
Research Baseline
        ↓
Competing Hypotheses
        ↓
Candidate Experiments
        ↓
Deterministic Selection
        ↓
Numerical Execution
        ↓
Observation
        ↓
Hypothesis Evaluation
        ↓
Confidence / Uncertainty Update
        ↓
Next Experiment
        ↺
```

The LLM proposes and reasons. Deterministic computational infrastructure performs the benchmark experiment. Evidence determines the next decision.

## What Is Novel in the Prototype

The prototype is not simply an AI system that generates scientific text.

It demonstrates:

**AI reasoning → falsifiable hypotheses → deterministic experiment → computational evidence → hypothesis update → next experiment**

The key architectural boundary is that the language model does not generate the experimental observations used to update the hypotheses.

## Demonstration Scope

This is a hackathon prototype demonstrating an architecture for agentic computational scientific discovery.

The superconductivity benchmark demonstrates iterative hypothesis testing and experiment selection. It does **not** claim that the resulting values constitute laboratory-confirmed scientific discovery.

The goal is to demonstrate how an agentic system can move beyond hypothesis generation toward an executable, evidence-driven scientific discovery loop.
